# TT Vlog 可逆滚动舞台设计

## 目标与范围

参考 Anime.js 官网 Scroll Observer 所体现的滚动同步交互，不复制品牌、素材或文案。在当前首页首屏与个人介绍之间加入一段连续停驻舞台，保留导航、主题切换、个人介绍、兴趣内容及现有轻量入场效果。

用户已选择「停驻舞台联动」方案。不采用仅强化渐入的方案，因为它缺少明确的连续演变；不采用整页分镜重构，避免扩大内容改动和滚动负担。

## 交互契约

舞台外层提供滚动距离，内层使用 CSS sticky 停驻。以外层顶部到停驻结束之间的滚动距离映射 0–1 进度，并驱动暂停的 Anime.js 时间线。下滚推进，上滚按同一进度回退；不依靠播放/倒放触发，不拦截滚轮、触摸或键盘。卡片 y/scale 使用包含停留区间的连续关键帧轨道，避免 Anime.js 分离动画之间的空档保留反向 seek 历史状态。

三个阶段连续衔接：

1. 0–约 30%：彩色几何元素围绕轨道聚合，展示探索主题。
2. 约 30–75%：几何展开、兴趣卡片错峰显现，展示 Move / Build / Learn。
3. 约 75–100%：卡片有序收束、结尾标题显现；停驻自然结束，进入原有个人介绍。

舞台内提供 Scroll to explore 提示、阶段标签和进度显示。提示为装饰或真实锚点，不使用无法操作的假按钮。阶段文字不通过 aria-live 在滚动时反复播报。

## 组件与动画边界

新增独立 Astro 舞台组件，拥有其 DOM、样式及滚动测量。Welcome 负责引入和放置，并监听舞台根节点冒泡的 `scroll-stage:layout` 事件，重新测量下游内容并更新滚动状态；不参与舞台动画。舞台通过限定根节点高度变化的 ResizeObserver 在布局完成后发出该事件，覆盖减少动态效果、短视口和静态回退的切换，不由逐帧动画写入触发。所有舞台动画选择器限定到组件根节点，不复用现有 section-copy / hobby__card 等动画选择器，避免两套时间线争用同一 transform。

复用已安装的 animejs，不新增运行时依赖。滚动事件为 passive，更新合并到 requestAnimationFrame；尺寸改变后重测并立即恢复当前进度。进度通过边界钳制处理首尾与超短页面距离。读取位置与写入样式分离，避免逐元素循环测量。

## 自适应与可访问性

桌面端舞台建议约 260vh，停驻高度适配视口；移动端约 220vh，缩小轨道与卡片位移，保持文字和卡片在屏幕内。最终数值以实际浏览器检查为准，不改变自然滚动语义。保留已有页面锚点及 base-aware 资源规则。

prefers-reduced-motion: reduce 时取消长距离停驻与滚动变形，直接显示静态标题和全部兴趣卡片，确保无 JS 时也能阅读有效内容。动态切换偏好时更新展示与测量。暗色与浅色均使用现有主题变量或对应可读配色。

## 验收

- 舞台 0%、中间和 100% 位置有明确不同的编排状态。
- 从后半段上滚至前半段，恢复相同位置对应的状态，不重复触发独立播放。
- 结束后可正常进入介绍、兴趣和页脚，导航锚点不被劫持。
- 桌面与移动端无横向溢出；减少动态效果模式下内容可读且无长空白。
- pnpm build 通过；启动开发服务并用浏览器检查双向滚动、主题与响应式表现。
